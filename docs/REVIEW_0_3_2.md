| P2 | 必须到达的消息重试耗尽后，数据库已 failed，报告仍称 retrying。 | 根据持久化返回的最终状态分类报告。`tests/test_dispatcher.py`。 |
| P2 | 最近一轮工具交换超过会话窗口时，从工具结果中间截断；SDK 会清除孤立结果，丢失已执行动作的上下文。 | 最新一轮即使超过条目上限，也保留完整 user/tool 交换，避免将截断当作新历史。`tests/test_sessions.py`。 |

| P2 | Docker SDK 关闭等待被取消或超时后，client 可能永远不关闭。 | 在同一执行线程中预先排入最终关闭，等待方退出不取消关闭；重复调用可等待同一结果。`tests/test_v3_docker_sdk.py`。 |

| P2 | Live 测试忽略已注入的环境密钥，只查固定 `.env`；缺少该文件时整套被跳过，容易误判真实验证已经完成。 | 环境变量优先，文件仅作可选回退；明确开启 live 却缺少密钥时失败。密钥不复制到文件。`tests/test_live_credentials.py`。 |

## 真实验收

### OpenAI API

使用官方 API 和 `gpt-6.1-sol`，中等 reasoning，测试输入均为合成数据。先验证鉴权与可用模型，再验证真实工具调用、历史回放和费用记录；随后运行整个既有 live 套件。

- 首轮探针：2 项通过，本地记录模型费用约 **$0.0259**。
- 既有完整 live 套件：**24 passed / 3 skipped**，约 **$0.3403**，耗时约 320 秒。
- 覆盖中文/英文对话、时间认知、记忆跨会话、技能加载、图片、MCP、托管搜索、定时、后台安静策略、任务进度、压缩、历史检索、记忆整理和内置行为评测。
- 跳过的 3 项：macOS 录音生成工具缺失；当前 Linux 测试环境没有本机 shell 沙箱，两个依赖该沙箱的测试不能运行。

这里的金额由项目记录的 usage 和内置价格表估算，仅包含模型调用；以供应商账单为准，不等同于完整账单核对。

### 真实 Web 进程

新增 `tests/live/test_live_web.py`，启动真正的 `python -m personal_agent serve` 子进程，通过本机 TCP/HTTP 验证：

1. `/healthz`、公开页面、未登录拒绝访问、一次性配对与鉴权 OpenAPI。
2. 表单提交、同一 `client_id` 重复交付只生成一次处理、SSE 收到真实模型回答。
3. 优雅停止并重启同一私有数据目录，保留 cookie、历史与上一轮随机口令，再做一次真实续问。
4. 私人空间与空项目隔离、退出后旧会话立即失效。

配置和测试内容使用临时私有目录；密钥只经进程环境注入，配对码与 cookie 不写入报告。测试清理会停止子进程，不在机器上遗留无人管理的付费调用。

实际结果：**1 passed**；补齐公开页面和已构建资源的 HTTP 检查后再次运行，仍为 **1 passed**，约 14 秒。两次模型费用估算分别为 $0.0090、$0.0013。与前述探针及完整 live 套件合计，本轮记录约 **$0.3765**。按不同测试统计，真实模型功能测试共 **25 项通过、3 项受环境限制跳过**；重复探针不计入该通过数。

## 本轮没有验证的边界

- Railway 的生产域名、卷权限、持续运行和自动部署状态；本机测试通过不等于生产已上线。
- 用户自己电脑上的真实 Docker 容器、Tailscale/手机网络、远端 SFTP、Telegram/钉钉等实际渠道凭据与平台权限。
- 真实 iOS 浏览器的 Service Worker 升级和后台断网恢复；本轮针对这些规则运行了前端回归，但未做真机验收。

撤权检查能阻止后续尚未发送的帧，不能撤回浏览器已经收到的内容。控制服务继续使用单副本 SQLite；没有引入分布式部署承诺。

## 复现

```bash
uv sync --frozen
npm ci
scripts/check.sh

# OPENAI_API_KEY 由终端或私有运行环境注入，不放入命令参数或仓库。
PA_LIVE=1 uv run pytest tests/live -q

# 仅验证真实 Web 进程、模型、重启恢复。
PA_LIVE=1 uv run pytest tests/live/test_live_web.py -q

# 可选：对已校验的自有 restic 二进制做真实本地验收。
PA_TEST_RESTIC_BINARY=/trusted/bin/restic uv run pytest tests/test_v3_restic.py -q
```

默认离线质量门禁不会调用付费模型。Live 测试显式开启才运行，并继续受每次运行和场景预算约束。0.3.2 没有数据库 schema 升级；更新代码和已锁定依赖后重启既有服务即可。
