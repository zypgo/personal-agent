# 0.8.0：改名栖序，换了图标和外观

这一版把产品改名叫栖序（Qixu），界面照着新图标重新配了色，图标里的 Q 和叶子在界面里动了起来。功能和接口没有变，没有数据库迁移，没有新增依赖。

## 名字和图标

- 产品名是栖序，英文 Qixu。网页标题、登录页、菜单、手机桌面图标下面的名字，都是“栖序”。标签页写成“助手名 · 栖序”；助手本身也叫栖序时，只写一次。
- 图标是深林绿的圆角底，奶油色的 Q，Q 的尾巴是一片叶子。浏览器图标、iOS 桌面图标（180 像素）和安卓的遮罩图标，都用它重画了。
- PNG 图标由 `scripts/make_icons.py` 直接从 `icon.svg` 画出（只用标准库），有测试核对两者没有错开。以后换图标，改 SVG，再跑一遍 `uv run python scripts/make_icons.py` 就行。
- 新建的助手默认叫“栖序”。已经装好的不受影响：名字写在你的 `config.toml` 里，想改随时改。
- 菜单第一项“个人助理”改叫“对话”。
- 命令行还是 `pa`。项目名 `personal-agent`、Python 包 `personal_agent`、数据目录 `~/.personal-agent`、`PA_*` 环境变量、launchd 标签和备份标签，都沿用原来的，旧的部署不用改。`pa --version` 现在先写 Qixu，后面括号里还是 `personal-agent`。

## 外观

聊天页和各栏目页仍然共用同一份 `tokens.css`，这次主要是换了里面的值。

| 部分 | 做法 |
| --- | --- |
| 配色 | 浅色是米白的纸面、深林色的字；深色是夜里的森林、奶油色的字。强调色，浅色下是深林绿，深色下是叶子的浅绿。链接是青灰蓝。正文、辅助文字、状态色的对比度，仍由测试逐项计算 |
| 叶子绿 | 只用在“在生长的东西”上：进度、好消息、图标里的叶子 |
| 栏目色 | 对话是林绿，任务是青蓝，资料是琥珀，助手是紫，项目是新叶绿，设备是灰绿。图标底座和选中态用栏目色；当文字用时，先向正文色调和 |
| 形状 | 圆角各放大了一两个像素，更圆润；阴影的底色换成深林绿，不再发灰 |
| 动效 | 弹性和缓出两条曲线不变，多了一条慢的摇摆曲线，只给“活着的东西”用（叶子、Q） |

## 图标在界面里的样子

图标拆成两块：Q 的弧线，和作为尾巴的叶子。它们可以各自动。

- 欢迎页：Q 先画出来，叶子接着长出来，之后叶子轻轻摇。背后有一圈淡淡的光，慢慢涨落；两颗小点像花粉一样绕着它转，还有一片小叶子晃个不停。
- 对话的头部、助手的发言标签、等待回复时的提示，用同一个小标记。空闲时轻轻呼吸；助手在忙时，弧线转起来；有事要你处理时，叶子晃一下并微微发亮；断线时变灰。
- 登录页、离线页和启动画面：直接用完整的图标，也就是深色底的圆角方块。
- 菜单顶部是“标记 + 栖序 + Qixu”。
- 任务页的空状态是一片叶子，后面还有一片小的。
- 系统开了“减少动态效果”时，这些全部静止。

## 在真实渲染里发现并修好的问题

| 问题 | 修复 |
| --- | --- |
| 整页铺一层绿色的光晕，浅色下顶栏玻璃下面露出一道接缝，深色下光晕有色带 | 去掉整页光晕，光只留在小的地方：欢迎页的 Q 背后、登录页的角落 |
| 登录页的图标方块里，Q 看不见：内边距用了百分比，算的是整个页面的宽，不是方块的宽 | 内边距按方块自己的尺寸算 |
| 登录页的图标方块只有 32 像素，不是设计的 72 像素：公共的默认尺寸盖过了登录页自己的尺寸 | 登录页的规则提高优先级 |

## 更新与回退

按原来的部署流程更新就可以。页面文件每次都会向服务端校验（ETag），不用手动清缓存。正在运行的服务，页面是启动时读进内存的，重启之后才会换成新页面和新名字。

手机上已经添加到桌面的应用，不会自动换图标和名字：删掉，再从浏览器重新添加一次。

没有数据库迁移，需要的话可以重新部署 0.7.1，现有的数据照常能用。
