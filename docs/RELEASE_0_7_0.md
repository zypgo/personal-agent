# 0.7.0：更灵动，更像一个原生应用

0.7.0 把整个前端从头到尾打磨了一遍：视觉、动效、手势和操作动线。能力沿用 0.6.1，没有新增服务、前端依赖和数据库迁移，接口也没有变。

这是第一个在真实视口里，一页一页看过渲染结果的版本：手机、小屏手机、平板和桌面，浅色和深色，登录前、离线和有数据的状态都看过。0.6.1 的发布说明里坦白说过，登录之后的桌面和手机视觉还没有实测；这一版补上了，也修掉了只有看到画面才会发现的问题。

## 设计语言：柔和的玻璃感

聊天页和各栏目页，共用同一份 `tokens.css`：颜色、字号、圆角、阴影、玻璃效果和动效曲线，只定义一次，两个页面不会再各改各的。

| 层面 | 做法 |
| --- | --- |
| 色彩 | 浅色是纸白，深色是深林绿。同一份令牌，用 `light-dark()` 同时描述两种外观，不支持它的浏览器，回到浅色。正文、辅助文字、状态色和图标的对比度，由测试逐项计算 |
| 字体 | 仍然只用系统字体（含苹方），字号分统一的几档；不请求外部字体或图片 |
| 形状 | 统一的圆角阶梯。支持连续曲率圆角（squircle）的浏览器，用它来画卡片、输入框和按钮，其余的回落成普通圆角 |
| 层次 | 三档阴影；顶栏和输入区，是半透明的模糊玻璃，内容从它们下面滑过 |
| 动效 | 弹性和缓出两条曲线、三档时长；只有新出现的内容，才有入场动画。系统开启“减少动态效果”时，动画、过渡、页面转场和平滑滚动，全部关闭 |
| 栏目色 | 对话是陶土色、任务是鼠尾草绿、资料是琥珀色、助手是紫色、项目是蓝色、设备是灰绿色。图标底座和选中态，用栏目色；栏目色当文字用的时候，先向正文色调和，保证看得清 |

## 对话

- 头部的四瓣标记，会随状态变化：空闲、正在忙、等你处理、连接中断。
- 助手的回复，边生成边排版，标题、列表和代码，在文字到达时就位，不会等整段结束，再一次跳变。
- 输入区是一个圆润的胶囊：附件在左，语音在右；输入文字之后，语音变成发送。多行输入，随内容增高。
- 欢迎语会按时段问候；四个快捷起点，只把示例填进输入框，不会替你发送。
- 助手在做什么，用日常说法描述，比如“正在搜索网页…”“正在阅读文件…”，而不是内部的工具名；不认识的工具，统一说“使用工具”。
- 临时的反馈，用提示条；偏好设置和图片预览，从底部升起。在手机上，按住顶部的抓手向下拉，就可以放下，轻扫一下也行。

## 菜单与操作动线

- 手机上，在页面空白处向右拖动，就能拉出菜单，菜单跟着手指展开；松手的时候，按位置和速度，决定是打开还是回弹。向左拖动、点遮罩或按 Escape，就收起。屏幕最左侧的一条窄边，留给浏览器的返回手势；在输入框、代码块、表格和对话框里的拖动，不会触发菜单。
- 菜单展开时，焦点进入菜单，并被限制在里面，收起之后，回到触发它的按钮。桌面端展开菜单的时候，页面里不再重复出现一个菜单按钮。
- 聊天页和各栏目页之间，交叉淡入；栏目页内部，切换任务、资料、助手、项目、设备的时候，在同一页里过渡，同时更新标题和菜单的选中项。
- 栏目页向下滚动之后，顶栏会显示当前栏目的名字，回到顶部就恢复，不管滚多远，都知道自己在哪一页。
- 保存成功、已取消这类提示，浮在顶栏的下方，不随页面滚动，几秒之后自己消失，点一下就可以收起；出错的提示，不会自动消失。

## 栏目页

- 每个栏目，都有大标题、一句说明和带栏目色的图标底座；操作按钮在手机上，缩进到文字的下方，不再和标题错位。
- 创建表单，收在一张卡片里，点加号展开，再点收起。任务页的“助手协作 / 电脑任务”，是带滑动指示的分段控件。
- 各栏目的卡片，用同一组间距、圆角和阴影；所有折叠项，用同一个会随展开旋转的箭头。
- 手机上的对话框（一次性代码、资料历史），以底部面板的方式出现。含一次性代码的对话框，只能用“完成”或 Escape 关闭，点背景不会误关。

## 在真实渲染里发现并修好的问题

| 问题 | 修复 |
| --- | --- |
| 手机上向左滑动，关不掉菜单：浏览器把横向拖动当成页面平移，手势传不到菜单 | 菜单和遮罩声明只接受纵向平移和双指缩放；打开和关闭两个方向，都用真实的触摸序列验证过，并有测试守住 |
| 滚动之后，保存成功等提示留在页面顶部，已经滚出屏幕，看不见 | 提示改成固定浮在顶栏下方，几秒之后自己消失 |
| 辅助文字（时间、占位符）的对比度，浅色下只有 2.9:1，深色下只有 2.6:1 | 提高到不低于 4:1；测试按两种外观，计算所有文字和底色的对比度 |
| 栏目色直接当文字用，琥珀色和浅蓝色在纸白上很难读 | 文字用向正文色调和之后的颜色，图标底座保持原色；有测试守住 |
| 浏览器自带的折叠三角，在聊天卡片和栏目页里，大小、位置不一样 | 统一成同一个箭头 |
| 桌面端菜单展开的时候，页面里还有一个重复的菜单按钮 | 展开时隐藏；开合的时候，键盘和触摸，分别处理焦点 |
| 手机上，标题旁边的操作按钮换行之后，挤在标题下面 | 缩进到文字列的下方对齐 |
| 平板上，创建卡片的加号跑到标题前面；手机上，卡片左侧的留白太大 | 只在手机上调整顺序，统一卡片的内边距 |

另外还有一处和界面无关的修复：在 macOS 上，Git 子进程因为输出超限被终止的时候，进程组可能只剩下已经退出的残留，系统会回答“无权限”，而不是“进程不存在”，这个错误会盖住本来该报告的“结果超过上限”。现在和沙箱的终止逻辑保持一致，忽略这种情形，报告真正的原因，并有确定性的回归测试。

## 更新与回退

按原来的部署流程更新就可以。页面文件每次都会向服务端校验（ETag），更新之后，不用手动清缓存；私人 API 和凭据，不进入离线缓存；浏览器本地，仍然只保存外观偏好和菜单展开的选择。没有数据库迁移，必要的话，可以重新部署 0.6.1，现有的持久数据保留。
