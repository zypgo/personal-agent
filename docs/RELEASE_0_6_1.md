# 0.6.1：给日常，多一点从容

本版继续把 Personal Agent 做成面向个人的产品。默认聊天、可收起菜单与全部底层能力沿用 0.6.0，集中调整视觉、反馈和容易打断操作的细节。没有新增服务、前端依赖、数据库迁移或后端业务逻辑。

## 设计

原创四瓣标记贯穿连接入口、菜单和聊天。欢迎区用轻量轨道图形表达想法逐步展开；四个快捷起点分别是理清待办、安排提醒、整理资料、交办任务。快捷入口仅准备输入，不替用户发送或发起工作。

画布改为纸白，正文采用深灰绿，陶土色突出主操作，鼠尾草绿与淡紫区分内容。深色外观使用深绿底色与浅字。继续使用系统字体与本地 SVG/CSS 图形，不请求外部字体或图片。

| 页面 | 调整 |
| --- | --- |
| 个人助理 | 两行欢迎标题、四个图形入口；输入区分开文字和操作栏，附件、语音与发送仍是原能力 |
| 菜单 | 四瓣品牌标记、图标底座、明确选中态，开合有短过渡；桌面记住收起选择，手机保留遮罩和焦点约束 |
| 待办卡片 | 类型标签、内容和操作分层；忙碌提示依据真实请求，审批与成果验收保持原确认步骤 |
| 任务 | 圆角类型切换、选中卡片、紧凑步骤时间线；移除原来步骤顶部不必要的大段留白 |
| 资料 | 目录与编辑区分层、纸页空状态；保存后的历史入口立即可用 |
| 助手、项目、设备 | 独立栏目图形、分组表单与空状态，保留管理和连接的全部入口 |

动效仅用于首次出现、悬停、点击和真实忙碌状态。装饰没有循环漂浮；移动触摸不依赖悬停才能发现操作。系统减少动态效果时关闭动画、过渡和主动平滑滚动。

## 复核与修复

| 问题 | 修复 |
| --- | --- |
| 多图导入部分失败，已成功的附件没有预览却可发送 | 在成功或失败结束时同步附件预览；保留现有数量预留与会话隔离 |
| 编辑失败消息覆盖当前新草稿，或超过图片上限 | 有输入、附件或媒体准备时保持两份内容原位；恢复前再次校验图片上限 |
| 输入框延迟焦点回调在退出后访问旧页面 | 延迟回调核验原 composer 仍属于当前会话 |
| 手机双指放大被当作键盘弹出，强制缩高并滚到底 | 只在正常缩放比例应用键盘补偿；放大阅读保留滚动位置 |
| 移除附件按钮被滚动容器裁切，热区过小 | 按钮放进缩略图边界，点击区域扩大为 44px |
| 快捷指令标成列表框，却没有相应方向键行为 | 使用真实按钮组语义，沿用 Tab 与点击操作 |
| 切换外观重建按钮，导致键盘焦点丢失 | 保留按钮节点，仅更新选中状态，使用 `aria-pressed` |
| 麦克风等待权限时禁用按钮导致失焦，录音开始后难以停下 | 禁用前记住触发焦点；权限返回后按实际焦点决定是否接力，结束后恢复；不抢走用户主动移开的焦点 |
| 新资料首次保存后历史按钮被旧状态再次禁用 | 提交结束后按新 revision 恢复历史按钮，失败时仍保持正确状态 |
| 重复点击当前任务，重绘并丢失详情草稿 | 电脑与协作任务在当前详情有草稿或提交在途时，保持编辑对象 |
| 取消保存连接的确认框后，草稿保护被清除 | 取消返回明确结果，表单仅在实际完成时清除 dirty 标记 |
| 编辑连接使用固定平滑滚动 | 与其他页面一致，尊重减少动态效果偏好 |
| 长助手名可能挤入头部按钮区域 | 标题限制在实际可用宽度内并截断，保留菜单和待办操作 |

所有动态内容仍使用安全 DOM 构建。没有改变身份、空间与成员权限、执行确认、审批版本、消息去重或卡片执行屏障。
