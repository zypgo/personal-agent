# 知识库：和 Obsidian 一起用

知识库就是一个文件夹，里面是 Markdown 笔记。你、栖序、接进来的其他助手都往里写，Obsidian 直接打开这个文件夹就能看、能改。

文件就是真相。你在 Obsidian 里改了什么，栖序下一次读到的就是什么，不用同步，也不用导入。

## 一分钟上手

1. 用 Obsidian 打开：**管理仓库 → 打开文件夹作为仓库**，选知识库所在的文件夹。不知道在哪，运行 `pa vault`，第一行就是；或者运行 `pa vault open`，直接交给 Obsidian。
2. 想让笔记放进你已有的仓库，在 `~/.personal-agent/config.toml` 里写：

   ```toml
   [vault]
   path = "~/Documents/笔记/栖序"
   ```

   默认放在 `~/.personal-agent/vault`。只有你自己的空间用这个路径，每个项目有自己的文件夹。
3. 在栖序里：菜单里的 **知识库** 可以搜索、读、写和看历史；也可以直接在聊天里说“记一下：预算每月五号提交”“上次预算那件事是怎么定的？”。

改了 `config.toml` 要重启 `pa serve` 才生效。

## 文件夹里有什么

| 文件夹 | 放什么 | 谁来写 |
| --- | --- | --- |
| `wiki/` | 留下来的知识：人、项目、决定、做事的办法 | 你和栖序 |
| `raw/` | 外面来的原始资料：助手交回的报告等。原样保存，之后不再改 | 栖序自动存 |
| `threads/` | 交给其他助手的任务，每个一篇：做到哪、结果在哪 | 栖序自动记；「笔记」那一段留给你写 |
| `daily/` | 每天发生了什么 | 栖序自动记，你也可以写 |
| `wiki/index.md`、`wiki/log.md` | 目录，和按时间排的改动记录 | 自动生成，手写的会被覆盖 |

这几个文件夹之外的东西，栖序不碰：你在仓库里的其他笔记、附件、`.obsidian` 设置，都原样放着。

## 和“记忆”有什么不同

记忆（`~/.personal-agent/memory`）是栖序自己的笔记：你的偏好、跨好几次唤醒的任务进度，只给它自己用。知识库是给你和所有助手一起用的：人、项目、决定、助手交回的资料，在 Obsidian 里能看、能改、能画关系图。

## 笔记怎么写

就是普通的 Markdown。开头可以有一段属性，Obsidian 的“属性”面板能直接看到：

```markdown
---
title: 预算流程
type: process
status: active
tags: [财务]
aliases: [报销流程]
---
# 预算流程
每月五号提交，负责人 [[张三]]。
```

- `[[笔记名]]` 按文件名链接，不用写路径。Obsidian 的反向链接、关系图直接能用。
- `private: true` 的笔记，栖序和其他助手看不到。整个文件夹不想给它们看，在 `config.toml` 里写 `[vault] exclude = ["私人"]`。
- `origin` 记着这篇是谁的话：`owner`（你）、`assistant`（栖序）、`agent`（别的助手）、`web`（网页）、`tainted`（栖序读了外面的内容之后写的）、`system`（系统生成）。栖序写的笔记会自己带上，它没法冒充你。

## 栖序怎么用它

- **先查再答。** 你提到某个人、项目、决定，它会先翻知识库，不凭印象答。
- **值得留的才记。** 一个决定、一个事实、助手查到的结论，写成一两句，链到相关的笔记。闲聊和能再查到的东西不记。
- **往已有的笔记里加，不另起一篇。** 不是它写的笔记，除非你要求，它不整篇改写。
- **外面来的话只当资料。** 助手交回的结果存进 `raw/agents/<助手名>/`，任务笔记里只放链接。读到这类笔记的那一轮，它写出来的笔记会标上 `origin: tainted`。
- **不写密钥。** 笔记里出现像密钥或口令的文字，写入会被拒绝。

### 每夜整理

每天夜里的“做梦”（见 [README 里的“记忆和做梦”](../README.md)）也会整理知识库，但守得更紧：

- 只在 `wiki/` 和 `daily/` 里**新增**，或者往它自己写的笔记后面追加。你写的笔记它不碰；想关联，它新建一篇，用 `[[链接]]` 指过去，Obsidian 里自然会出现在被指向的笔记旁边（反向链接）。
- 看一眼 `raw/` 里还没有被 `wiki/` 链接的资料（一次最多五篇的标题），每次最多读三篇，把意思写成 wiki 笔记，链回原文，不抄原话。
- 一晚最多新建 6 篇（`[dreaming] max_new_notes`），想多想少自己改。
- 这一轮没做完，或者因为删记忆太多被整个撤销，它写进知识库的笔记也一并撤回。

### 都能撤销

栖序写的每一笔都有历史，保留 180 天（`[vault] history_days`）：

- 网页里：知识库 → 打开一篇 → **历史**，选一个版本恢复。
- 命令行：`pa vault log` 看最近的改动和版本号，`pa vault restore 版本号` 把一篇放回去，`pa vault undo 某次运行` 撤回那一轮写的全部。你在这之后改过的笔记不会被覆盖，会提示留着没动。

## 多个助手怎么共用

- 每个项目空间有自己的知识库，谁能读写，跟项目里的角色一致（查看者只读）。个人空间用 `[vault] path`。
- 接进来的 Grok、Muse、你自己的 Agent 交回结果时，栖序把它原样存到 `raw/agents/<助手名>/日期-标题-编号.md`，属性里记着是哪个助手、哪个任务、哪一步、结果怎么样。同一份结果存两次，只会有一篇。
- 升级之后交出去的任务，每个在 `threads/` 里有一篇自己的笔记：做什么、谁在做、经过、结果链接。升级之前就有的任务不补记。笔记里只有「笔记」那一段能让你和栖序补充，其余由系统随任务更新。
- 任务页上，有笔记的任务会多一个“在知识库里看这条线索”，一点就打开这篇笔记。
- 助手之间不直接对话。想让一个助手用到另一个助手的结果，让栖序先读 `raw/` 里的笔记，需要的话写成 `wiki/` 笔记，再带进下一次派活。

## 命令

```bash
pa vault                       # 文件夹在哪、有多少篇、有什么要看一眼
pa vault search 预算 --folder wiki   # 按文字、标题、标签找
pa vault lint                  # 断掉的链接、没人链接的笔记、还没整理的资料、重名
pa vault open [wiki/张三.md]   # 交给 Obsidian；--print 只打印地址
pa vault index                 # 马上重写目录（wiki/index.md）
pa vault log                   # 最近的改动，带版本号和运行号
pa vault restore 42            # 把某一篇放回那次改动之前
pa vault undo 运行号            # 撤回某一轮写的全部
```

这些命令只看和撤销，不改笔记的内容。写笔记在网页、Obsidian 或聊天里。

## 设置

```toml
[vault]
enabled = true          # false 关掉整个知识库
path = ""               # 空则用 ~/.personal-agent/vault
exclude = []            # 栖序不看的文件夹名，如 ["私人"]
capture_results = true  # 助手交回的结果存进 raw/agents/
max_note_bytes = 262144 # 栖序写的单篇上限
max_files = 5000        # 最多搜多少篇，更多时取最新的
view_max_chars = 12000  # 栖序一次读一篇的字数
history_days = 180      # 改动能撤销多久，0 为一直保留

[dreaming]
max_new_notes = 6       # 每夜最多新建几篇
```

## 常见问题

**我在 Obsidian 里改了，栖序多久能看到？** 下一次读的时候就是新的。它每次先看文件有没有变。

**栖序和我同时改一篇笔记会怎样？** 栖序整篇改写前要带上它读到的版本；你中间改过，它的改写会失败，让它重读再来。往后面追加不受影响。文件是整个替换写入的，Obsidian 不会读到写了一半的内容。

**以前的“资料”呢？** 第一次启动时自动搬进 `wiki/`，一次，原文件不删。之后在旧入口保存的资料，也会同步一份到 `wiki/`。

**笔记很多会慢吗？** 索引放在内存里，按文件修改时间增量更新。超过 `max_files` 篇时只搜最新的那些。

**能放进 iCloud、Git 或 Obsidian Sync 吗？** 可以，它就是普通文件夹。写入用临时文件加替换，同步软件不会看到半截文件。

**想看某篇是谁写的、什么时候改的？** 属性里的 `origin` 是谁的话，历史里有每一次改动的人和时间。
