# 0.7.1：安全边界与日常使用修复

本版基于 0.7.0 的 `c187d020aa4259b91921d9d621fb3756da25c701` 做代码审查与缺陷修复。保留现有界面、Agent 工具、记忆、提醒、审批、渠道、协作和执行能力，无数据库迁移或新增依赖。

## 确认并修复的问题

| 范围 | 触发条件与原有问题 | 修复 |
| --- | --- | --- |
| 文件访问边界 | 列目录前已经校验路径，但并发操作把该目录或祖先换成工作区外的符号链接，仍可能列出外部文件名和大小 | 从可信根通过目录描述符遍历，各级目录拒绝跟随后来出现的链接；元数据查询也不跟随链接 |
| 预算保护 | 扩额或配置接受 Infinity；扩额还接受 NaN，有限大额相加也可能溢出，导致支出上限失效 | 配置、CLI 和核心层检查有限值及加总溢出；旧库中的非法扩额回退到配置上限；同一天的增额在事务内累加 |
| 请求解析 | 低于请求大小上限的深层 JSON 抛出递归异常，接口返回 500，配对入口未计入失败限流 | 配对、审批及 V3/V4 JSON 入口统一返回 400；配对失败继续计入限流 |
| 手机面板 | 标题栏提前捕获关闭按钮的触摸，导致按钮收不到点击；第二根手指还可能覆盖拖动状态 | 交互控件不参与标题栏拖动捕获，保留单一主指针 |
| 图片发送 | SSE 先确认消息，POST 随后失败时，本地图片预览 URL 未释放 | 收到确认即回收本地预览，正式图片继续使用已授权媒体地址 |
| 菜单手势 | 拖动中旋转屏幕或跨布局断点，留下半开状态并阻塞后续手势 | 布局切换、开合及销毁时统一清理拖动状态 |
| 空间与账号切换 | 旧空间预算、设备数量及操作提示未跟随列表清空 | 登出、切换空间或权限变化时同步清理诊断与提示，取消旧提示计时器 |
| 发布配置检查 | 多个环境文件，或同一文件重复定义同名变量时，较早的敏感值被后值覆盖，扫描因此漏检 | 累积所有定义中的值，逐一检查；拒绝信息仍不显示值本身 |
| 发布标签检查 | 提交作者检查不覆盖附注标签自身的作者邮箱 | 检查新标签及嵌套标签作者；已有公开标签对象从本次发布范围排除，不重写或移动它们 |

这些是代码路径和隔离测试确认的缺陷，不表示发现真实账号已被入侵或真实数据已外泄。文件边界问题涉及目录元数据，没有在该路径发现读取外部文件内容的能力。

## 审查方法与验证

前端、后端和运行时分别审查，再由另一位审查者交叉复核。针对确认问题先建立失败回归，再修改实现；发布范围和预算配置的边界也根据交叉复核补齐。

验证使用临时目录、内存或临时数据库、本地合成 Git 远端与模拟模型，不调用生产服务或真实凭据。

- 项目完整质量门禁 `scripts/check.sh` 通过：格式、Ruff、严格 Mypy、Python 测试、前端契约、TypeScript、构建一致性及 JavaScript 测试。
- Python：**6027 passed，52 skipped**。跳过项为 28 项真实付费模型调用、23 项 macOS 专属验证、1 项依赖未安装的 restic；真实 Gitleaks 集成测试已运行。
- JavaScript：**257 passed，0 skipped**。本版新增 38 个 Python 与 5 个 JavaScript 回归及边界用例。
- 额外交叉验证：目录遍历途中替换子目录与祖先、文件描述符释放、两个数据库连接累计 100 次预算扩展、跨午夜预算，以及仅有远端标签时的首次发布与嵌套标签检查。
- OpenAPI 仅版本号更新，生成类型与前端构建产物一致；没有依赖变更。
- 发布隐私检查覆盖本次 26 个文件。官方 Gitleaks 默认规则的 2 处候选均与 0.7.0 已审计的合成测试值相同；未发现新增真实凭据或私人信息。

本轮触摸与界面回归使用自动化事件测试，未完成真实浏览器或 iOS 真机实测；也未执行生产 webhook 或真实模型端到端调用。审查和测试能够降低缺陷风险，不代表证明所有环境下绝对没有 bug。

## 更新与回退

按现有部署流程更新至 0.7.1。版本号同步到包、运行时和 OpenAPI；Service Worker 使用运行时版本管理公共页面缓存，私人 API 仍不进入离线缓存。

没有数据库迁移。原来保存的非有限预算扩额会按零处理；配置文件中的无限预算现在会被明确拒绝，需改成有限正数。必要时可重新部署 0.7.0，但本版修复的安全边界问题也会随回退恢复。
