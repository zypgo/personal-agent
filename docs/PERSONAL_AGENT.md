# 使用栖序

打开栖序，进来就是聊天。把想做的事告诉它：它会查已有的信息，准备好工作，再继续跟进。需要你决定的事，会在对话里变成卡片，在卡片上处理。左侧菜单里是任务、资料、连接这些管理页面，用的是同一份数据。

## 先做第一件事

部署好、浏览器也配对完之后，打开 **对话**。先从一件具体的小事开始，比如“帮我整理这段资料”“提醒我明天处理这件事”“看看有哪些任务要我回答”。页面上的快捷入口会把示例填进输入框，改一改再发送就行。

助理用的是菜单里当前选中的空间。私人空间放你自己的对话、记忆和任务；项目空间用来和项目成员一起做事。切换空间后，助理看到的资料、任务和能用的资源也跟着变。

## 菜单里有什么

点左上角的菜单按钮，展开或收起导航。电脑会记住你上次的选择；手机默认收起，在页面空白处向右拖就能拉出来，向左拖、点遮罩或按 Escape 就关上。

| 页面 | 平时用来做什么 |
| --- | --- |
| 对话 | 聊天、看待办卡片、提出下一件事 |
| 任务 | 看助手协作和电脑上的任务，核对计划和成果 |
| 资料 | 搜索、新建、编辑资料，看历史版本 |
| 助手与连接 | 接入已有的 Agent，管理连接 |
| 项目与成员 | 建共享项目，邀请成员、管理角色 |
| 设备与账号 | 连接电脑、登录其他设备、绑定聊天账号、准备恢复码 |

在同一个空间里切换页面，没提交的表单会保留。离开页面或切换空间前，如果有没保存的内容，会提醒你。资料正在保存时，要等这次保存结束，才能打开另一份。

页面地址可以直接收藏，比如 `/workspace?tab=knowledge`；带 `space` 的地址会记住选中的空间。

## 日常怎么用

### 整理资料，记住上下文

可以让助理找已有的记忆，把零散的信息整理成笔记，或者给某个项目准备一份资料更新。请说明要存到哪个项目；没说清楚时，助理会先问你。两个人同时改同一份资料时，后提交的会收到冲突提示，不会盖掉前面的。

例如：“把刚才讨论的旅行安排整理成一份资料，放进旅行项目。”要用到那个项目时，先切到对应的空间。

### 定时跟进

直接说清楚时间、多久一次、想要什么结果，比如：“工作日早上八点给我一份行业简报，有变化时重点说明。”定时任务用你配置好的时区和通知渠道。助理会记着任务进行到哪、最近通知过什么；想知道执行得怎么样，随时问它。

网页不是系统推送服务。想在关掉页面后也收到主动消息，请配置 Telegram 或钉钉，并完成账号和空间的绑定。

### 把工作交给电脑或其他 Agent

告诉助理目标、要用的资料和完成的标准。它会查有哪些执行端接入了，再准备执行或协作的计划。确认卡片会列出将要执行的内容，你批准后才会派出去。

多个 Agent 可以同时做、依次接力，也可以先并行再汇总。后面的步骤要等前面的成果通过验收才开始。“收到 webhook”“领到任务”“执行完成”“通过验收”是四个不同的状态。

设备离线时，相关的执行任务会等它上线。你仍然可以查看任务、做别的对话。

## 在对话里做决定

| 卡片 | 你要判断什么 | 点完之后 |
| --- | --- | --- |
| 执行审批 | 要执行什么、输入和输出是什么、用哪台电脑 | 批准或拒绝这份计划 |
| Agent 协作计划 | 目标、接收方、要发出去的内容、步骤和验收标准 | 确认后派出去 |
| 补充问题 | 执行端需要你给的答案或选择 | 回答后，执行端继续处理 |
| 待验收成果 | 结果正文、文件、有没有达到标准 | 通过验收后，依赖它的步骤才继续 |
| 管理操作 | 项目、成员、资料、设备或连接具体要怎么改 | 在表单里填好并提交 |

卡片上的按钮，取决于你的身份、所在的空间和对资源的权限。已经处理过的、过期的，或者不知道执行到哪了的卡片，不会再显示成可以直接执行的新请求。

邀请码、配对码、恢复信息和连接凭据，只出现在表单里，不会进入对话。

手上有项目邀请码时，可以对助理说“帮我加入一个项目”。它会打开一个表单，输入邀请码，就用当前账号加入。

## 看进度，处理卡住的事

可以直接问：“这件事做到哪一步了？”“哪些地方要我处理？”“成果在哪？”想看全貌，从菜单里打开 **任务**。任务、资料和连接这几个页面，与助理用的是同一份数据。

如果一个操作可能已经提交了，但没有收到明确的回复，助理会把它标成“待核查”。先去看对应的任务或连接，再决定下一步。

批准或补充回答提交失败时，先点卡片区域的刷新；服务端如果还允许处理，卡片会重新打开。已经开始执行、或者结果不明确的管理操作，保持“待核查”。

停止任务要等真正执行的那一端确认已经停下来。外部 Agent 必要时还要到它自己的产品里看执行状态。

## 能用什么，由你的连接决定

模型、搜索、语音、聊天渠道、执行用的电脑、外部 Agent，都要各自配置。Grok 靠你配置好的 Routine 自动唤醒；Muse 通过它自己的会话或定时功能来领任务；Codex、Cursor 用你自己的电脑和你本人的登录。
