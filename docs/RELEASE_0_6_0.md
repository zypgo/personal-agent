# 0.6.0：聊天首页与产品菜单

## 本版目标

用户从对话进入 Personal Agent，通过自然语言与交互卡片完成日常工作；需要查看、编辑或管理时，打开对应功能页面。原工作台演变为可收起的菜单，底层能力沿用 0.5.0。

本版不引入新服务、付费沙箱、前端依赖或数据库迁移。API 字段与执行协议不变；后端修复仅涉及旧权限卡片占用当前额度的问题。

## 页面与动线

| 页面 | 第一件事 | 次要操作与保留能力 |
| --- | --- | --- |
| 个人助理 | 写下想完成的事 | 快捷起点、流式回复、图片、语音、历史、审批与待办卡片 |
| 任务 | 看进度与需要自己处理的事项 | 助手协作/电脑任务切换，计划审批、提问、结果验收、日志与文件 |
| 资料 | 搜索或打开已有资料 | 新建、编辑、保存、历史版本；保存时固定当前资料 |
| 助手与连接 | 查看已接入的助手 | 新建连接、编辑、轮换凭据、撤销、接入文件与停止核对 |
| 项目与成员 | 查看当前成员与角色 | 创建项目、生成邀请、修改角色、移除成员、加入项目 |
| 设备与账号 | 查看自己的设备与连接 | 配对、撤销、执行电脑、Telegram/钉钉绑定、恢复码、退出 |

导航采用同一份固定目的地列表。桌面默认展开并记住收起选择；手机默认关闭，展开后锁定背景、约束键盘焦点，遮罩或 Escape 关闭后把焦点还给菜单按钮。系统减少动态效果的偏好会关闭抽屉动画。

聊天欢迎区提供明确起点，输入框、消息、确认卡片统一使用原有暖纸色与系统字体。设置展示运行状态、今日花费、待确认数量和设备信息；完整状态查询仍通过原有 `/status` 命令提供。没有加入虚构任务、假数字或无实际动作的按钮。

原 `/workspace` 继续打开任务页。`?tab=tasks|knowledge|agents|spaces|devices` 定位栏目；`?tab=tasks&view=computer` 定位电脑任务。前进后退与刷新保留栏目和当前空间，未知栏目回到真实任务页。

## 复核发现与修复

| 问题 | 用户影响 | 修复与验证 |
| --- | --- | --- |
| 成员请求仍带旧 `action` 字段 | 修改或移除成员被严格契约拒绝 | 使用当前 DTO，真实前端请求回归 |
| 已登录接受邀请未钉住现有会话 | 撤权后存在错误恢复路径 | 提交 `require_existing_session: true`；复用已有身份/事务边界测试 |
| 旧权限提案仍计入40张上限 | 看不到待办，却不能生成新卡片 | 只对当前权限版本计数；旧执行回执仍保留，禁止重试语义不变 |
| 审批/取消失败后卡片一直锁定 | 刷新也不能继续处理 | 失败后的新授权读取才恢复，重新核对后操作；在飞请求与旧读取不能提前解锁 |
| 退出后的录音/音频解析继续完成 | 旧媒体可能进入后续登录的对话 | 销毁时取消录音，异步边界检查当前 UI 身份 |
| 重复登录积累拖放与视口监听 | 图片重复添加、旧页面回调继续运行 | 随页面销毁解绑，清理观察器与弹窗 |
| 并发图片导入按旧容量计算 | 超出图片数或图片未准备完就发送 | 导入前预留数量，准备完成后再允许发送 |
| 录音器构造/启动失败漏清理 | 麦克风音轨没有释放 | 初始化异常也执行幂等释放，保留正常录制与取消 |
| 保存资料时允许切换编辑对象 | 旧响应覆盖新资料版本与草稿标记 | 保存期间禁止打开/新建/关闭资料，完成后再切换 |
| 凭据与邀请按钮可被重复点击 | 生成多次操作或覆盖一次性信息 | 提交期间锁定按钮，完成后恢复 |
| 退出请求失败仍显示已退出 | 实际登录状态与界面提示不一致 | 明确区分本地清空与服务端确认 |
| 离页或切空间没有草稿保护 | 未发送文字、附件或表单内容丢失 | 只在确有未保存内容时提醒；不将私密草稿持久化 |

## 验证

完整门禁 `scripts/check.sh` 通过：

- Python：**5974 passed，24 skipped**。23 项需要 macOS，1 项需要本环境未安装的 restic；真实模型测试单独排除。
- JavaScript：**223 passed，0 skipped**，较 0.5.0 增加37项行为回归，覆盖菜单深链与移动焦点、媒体生命周期、卡片恢复、草稿保护和资料保存竞态。
- Ruff 格式与静态检查、Mypy 的203个源模块、TypeScript、API 类型生成及构建一致性全部通过。
- OpenAPI 与上版比较，仅 `info.version` 变化；现有客户端和执行端协议保持兼容。
- 更新的4份 CSS 通过语法解析。发布文件使用默认 Gitleaks 规则扫描，不依赖项目忽略规则，未发现密钥。

测试通过原有离线封装运行，移除环境中的模型、渠道与执行端凭据，避免触发真实任务。测试记录覆盖行为与静态结构，不证明视觉布局已在所有设备上验收。

实际浏览器的本地预览受到 URL 安全策略限制，本版未把本地样本或逻辑测试宣称为登录后页面的视觉验收。不会为获得截图而绕过限制、改生产鉴权或调用真实外部 Agent。线上检查仅观察已授权的公开页面，不创建生产任务。

## 升级与回退

按现有部署流程更新，保留原持久卷与配置，运行 `uv sync --frozen` 后重启。静态资产版本由实际文件内容生成，服务工作线程更新时包含新的菜单文件；私密 API 和凭据不进入离线缓存。

本版无 schema 迁移。需要回退时可重新部署 0.5.0；不删除持久化数据、任务或操作回执。
